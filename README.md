🚀 本地秒开  
**Launch locally in seconds**

```bash
git clone https://github.com/ybcstar/kimigamehub.git
cd kimigamehub
# 双击 index.html 即可
# Double-click index.html
# 或用任意静态服务器
# or use any static server
python -m http.server 8000
```

🛠️ 技术栈  
**Tech stack**

- 纯 HTML + CSS + JS，无构建步骤  
- Pure HTML + CSS + JS, zero build steps  
- 字体：MapleMono-CN-Regular（OFL 授权，见 `other/LICENSE/MapleMonoFont`）  
- Font: MapleMono-CN-Regular (OFL, see `other/LICENSE/MapleMonoFont`)  
- 主题：毛玻璃 + 打字机效果，全部写进 `temple.css`，可一键换色  
- Theme: glassmorphism + typewriter effects, all in `temple.css`, one-click recolor
